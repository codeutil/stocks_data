# S&P 500 Dashboard

Static S&P 500 dashboard with annual returns, valuation charts, market breadth, drawdown tables, and a metrics overview.

## Files

- `index.html` - app shell and view structure
- `styles.css` - layout and visual design
- `sp500-poster.js` - local data, rendering logic, charts, language switcher, and image export

## Publish With GitHub Pages

Create a GitHub repository, push this folder, then enable GitHub Pages:

1. Settings
2. Pages
3. Source: `Deploy from a branch`
4. Branch: `main`
5. Folder: `/root`

The page URL will be:

`https://<github-username>.github.io/<repo-name>/`
